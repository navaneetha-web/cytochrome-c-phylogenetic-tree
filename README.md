# cytochrome-c-phylogenetic-tree
Phylogenetic tree of 7 random species using MAFFT,MEGA and iTOL.

## Species used
Drosophila melanogaster, Arabidopsis thaliana, Trypanosoma gyri, Homo sapiens, Equus caballus, Bos taurus, Parachaetomium inaequale

## Tools
NCBI protein : Sequence retrievel
MAFFT : MSA (Multiple Sequence Alignment)
MEGA : Neighbour-joining tree
iTOL : Tree visualisation

## Files
cytochrome_sequences.fasta - input sequences
new.nwk - tree file
aligned.meg - aligned sequences
Phyloanalysis.png - Visualised figure
Phylotree.png - tree figure
Phylogenetic Tree Construction Using Multiple Sequence Alignment.pdf - Report file

## Result
Seven sequences formed two well-supported groups (bootstrap 89-100%).
Human, horse and cow clustered together indicating that they evolutionarily related.
